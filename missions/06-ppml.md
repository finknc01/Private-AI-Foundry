# Mission 06 — Privacy Is Not Security

## Briefing
Aster Labs proposes a privacy-preserving ML technique and declares the infrastructure problem solved.

## Objective
Place PPML techniques in the correct part of the threat model.

## Tasks
Pick one or more concepts you already understand—such as differential privacy, federated learning, secure aggregation, or confidential-computing concepts—and map which privacy risks they mitigate. Then map infrastructure risks they do not solve: stolen credentials, exposed management plane, malicious images, leaked secrets, unpatched host, or unrestricted storage access.

## Evidence
- threat → PPML/control coverage matrix
- architecture diagram showing where the privacy mechanism acts
- “not protected by this mechanism” section

## Victory condition
You can explain how privacy-preserving computation and infrastructure security complement rather than replace each other.
